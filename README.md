# 📘 DSA with LeetCode

Welcome to **DSA with LeetCode** – a curated collection of **Data Structures and Algorithms (DSA)** problems solved using **LeetCode**.  
This repository is designed to help learners, interview aspirants, and developers strengthen their problem-solving skills step by step.

---

## Features
- Organized solutions to popular **LeetCode DSA problems**
- Covers **arrays, strings, linked lists, trees, graphs, dynamic programming, and more**
- Clean, well-documented code with explanations
- Focus on **time complexity** and **space complexity**
- Ideal for **interview preparation** and **competitive programming**

---

Each file contains problems and solutions related to that question number on leetcode.

## Tech Stack
- **Language:** Java (primary)  
- **Platform:** LeetCode  
- **Tools:** GitHub for version control & collaboration
